API бэкенд простого приложения для списка дел

Используются Django/DRF, postgres, Swagger. 

Функционал приложения:
создание задачи
редактирование задачи
удаление задачи,
перевод в выполненные,
просмотр всех задач 
        с фильтром по тегам, статусу выполнения
        сортировкой по сроку, дате создания, заголовку
        и пагинацией.
